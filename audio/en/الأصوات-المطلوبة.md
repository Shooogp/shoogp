# الأصواتُ المطلوبةُ للغةِ الإنجليزية — الصف الأول

**الحال:** ٣١ ملفاً يطلبُها الكتابُ كلُّه · **١٥ موجودةٌ تعمل** · **١٦ ناقصةٌ** تُولَّدُ
بداريجات حين يعودُ المسار (كان معطَّلاً «الخوادم مشغولة» ٢٠٢٦-٠٩-١٥/١٦).

> **لا يُعادُ تأليفُ سؤالٍ عند وصولِ الصوت.** كلُّ سؤالٍ يحملُ حقلَ `audio` بمسارِه
> النهائيِّ سلفاً، فيكفي **إيداعُ الملفِّ في `audio/en/` بالاسمِ نفسِه** ليعمل.
> (طلبُ المالك ٢٠٢٦-٠٩-١٦: تُؤلَّفُ أسئلةُ الصوتياتِ طبيعيةً والملفّاتُ تُضافُ بعدُ.)

> **والترخيصُ محسوم** (§`contentPolicy.audioHeavyBook.licenseQuestion` في
> `en-question-types.json`): الاستهلاكُ عندَ التوليدِ مرّةً واحدةً، والاستعمالُ بعدَها
> غيرُ محدود — فالنمطُ: يُولَّدُ الملفُّ مرّةً ويُخزَّنُ هنا.

## كيف يُتحقَّقُ من اكتمالِ القائمةِ آلياً

```bash
node -e "
const fs=require('fs'),vm=require('vm');const c={window:{}};vm.createContext(c);
vm.runInContext(fs.readFileSync('js/questions.js','utf8'),c);
const Q=c.window.QUESTIONS,need=new Set();
for(const k in Q) if(k.startsWith('g1e-')) for(const q of Q[k]){
  [q.audio,q.blendAudio].forEach(a=>a&&need.add(a));
  if(q.soundOf) Object.values(q.soundOf).forEach(a=>need.add(a)); }
const have=new Set(fs.readdirSync('audio/en').map(f=>'audio/en/'+f));
console.log([...need].filter(a=>!have.has(a)).sort().join('\n')||'لا نقص');"
```
