# بنوك أسئلة الألعاب

- `gamebank-<كتاب>.json`: الأسئلة الجديدة المؤلَّفة للألعاب (٨ لكل درس: ٥ اختيار من متعدد + ٣ صح/خطأ). الإجابة الصحيحة أول خيار دائماً، واللعبة تخلط الخيارات.
- `mkdata_all.cjs`: يبني `games/data/<كتاب>.js` لكل الكتب من `js/questions.js` (الاختيار من متعدد والصح/الخطأ فقط) مع هذه البنوك:

```
node tools/games/mkdata_all.cjs . games/data
```

شغّله بعد أي تعديل على أسئلة الدروس أو البنوك.
